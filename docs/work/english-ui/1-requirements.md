# 需求：英文介面、字幕與彈幕翻譯（english-ui）

日期：2026-11-08

## 目標

讓不懂中文的使用者能使用 PiliBTR：介面可切換成英文，影片字幕與彈幕可翻成英文。

## 使用者決定（2026-11-08）

- 介面：開發時先翻譯好（agy／本地模型），做成語言包 `i18n/en.json` 放在 GitHub repo；使用者切換成英文時才下載，下載後離線使用。
- 字幕：有 B 站英文字幕（`en-*`、`ai-en`）時優先使用；沒有時翻譯中文字幕。
- 字幕與彈幕的翻譯：以手機上的離線模型（Google ML Kit，切換英文時下載約 30 MB 中翻英模型）為主；設定中填了 DeepL 或 Google Cloud Translation 金鑰時改用線上服務。
- 彈幕也翻譯。

## 驗收條件

### 介面

- **AC-1**：設定 → 外觀 → 語言 新增「English」。選擇後下載語言包（顯示進度，失敗時提示並維持原語言），完成後依現有流程重新啟動生效。
- **AC-2**：英文模式下，經過轉換層的固定文字（`Text`、`Text.rich`、`Tab`、`TextField` 裝飾、toast／通知）顯示英文；語言包沒有的字串顯示原本的繁體中文。
- **AC-3**：`IconButton.tooltip` 與 `Tooltip.message` 也會翻譯。
- **AC-4**：常見的夾帶變數字串（例如「N 分鐘前」「當前：N%」「N 排」）以樣板翻譯，語序正確。
- **AC-5**：與伺服器比對、解析用的中文字串（`to_traditional.py` 的 `PROTECT`、`num_utils.dart` 的單位、`chat_item.dart` 的「直播」等）不翻譯，功能不受影響。
- **AC-6**：Material 內建元件（返回鍵提示、日期選擇器等）在英文模式下顯示英文（Locale `en-US`）。
- **AC-7**：語言包有版本資訊；英文模式下 App 啟動時，若上次檢查超過 7 天則背景檢查更新；設定中有「更新語言包」手動更新。
- **AC-8**：影片標題、留言、簡介等伺服器內容不翻譯（維持原文）。

### 字幕

- **AC-9**：英文模式下，影片有 B 站英文字幕時預設選英文字幕（使用者手動選的不覆蓋）。
- **AC-10**：沒有英文字幕時，中文字幕整份翻成英文後再顯示；翻譯期間先顯示原文，完成後換成英文。字幕選單中翻譯過的軌道標示「(Translated)」。
- **AC-11**：翻譯來源依設定：未填金鑰用 ML Kit 離線模型；填了 DeepL 或 Google Cloud 金鑰則用線上服務，失敗時改用離線模型。

### 彈幕

- **AC-12**：英文模式且「翻譯彈幕」開啟（預設開啟）時，影片彈幕在封鎖／去重之後翻譯成英文再顯示；尚未翻譯完成的先顯示原文。直播彈幕也翻譯。
- **AC-13**：封鎖規則、去重一律使用原文比對。
- **AC-14**：彈幕翻譯一律使用離線模型（避免大量消耗線上金鑰額度）。

### 模型與設定

- **AC-15**：切換成英文時同時下載 ML Kit 中翻英模型（顯示進度）；未下載完成時字幕／彈幕維持原文。設定中可刪除模型。
- **AC-16**：設定 → 播放 → 字幕 新增「翻譯服務」：離線模型（預設）／DeepL（API 金鑰）／Google Cloud（API 金鑰）。金鑰存在本機。
- **AC-17**：翻譯結果有快取（同一句不重複翻譯）。
- **AC-18**：`flutter analyze` 無新增錯誤或警告；release 建置成功。

## 不做的範圍

- iOS、桌面平台的離線翻譯（ML Kit 只做 Android；其他平台字幕／彈幕維持原文）。
- 繁簡以外的其他語言（架構預留，但只做英文）。
- 伺服器內容（標題、留言、簡介）翻譯。

## 限制

- 新增相依套件 `google_mlkit_translation`（使用者已同意離線模型）。
- 語言包 URL：`https://raw.githubusercontent.com/gordonpow/PiliBTR/main/i18n/en.json`。
- 介面文字、註解用繁體中文或英文。
