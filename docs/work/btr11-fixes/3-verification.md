# 驗證：預覽載入圈、推薦卡片、全螢幕方向、CDN 預設與 CDN 狀態

日期：2026-11-07
環境：模擬器 `Medium_Phone_API_37.0`，debug APK（x64）。截圖在 session scratchpad `shots/`。

| AC | 結果 | 證據 |
|---|---|---|
| AC-1 預覽載入圈 | 通過 | 長按首頁卡片，預覽播放時沒有載入圈（p1） |
| AC-2 推薦直式卡片 | 通過 | 簡介中的相關推薦（r1）與全螢幕推薦面板（g1）都是直式卡片。橫向分欄時欄數依「影片卡片排數」設定，模擬器設為固定 5 排，所以側欄的卡片較窄（s4） |
| AC-3 縮小不轉直 | 通過 | 全螢幕中間下滑期間，每 0.15 秒讀一次 `dumpsys display`，20 次都是 `mCurrentOrientation=3`（橫向）；最後回到橫向首頁並顯示小視窗（s1） |
| AC-4 退出全螢幕維持橫向 | 通過 | 退出後顯示左右分欄（s4）；修正後沒有溢出 |
| AC-5 依系統語言設定 CDN | 未驗證 | 模擬器是英文系統，依規則不改動；需要在繁體或簡體系統的手機上全新安裝確認 |
| AC-6 CDN 狀態 | 通過（BTR 關閉） | 選單出現「CDN 狀態」，面板顯示影片與音訊的直連主機（c2、c3）。BTR 開啟時的節點列表未在模擬器測試 |
| 追加：橫向小視窗貼底 | 通過 | 小視窗底部貼齊螢幕邊緣（s1） |

## 測試中發現並修正

1. 手機橫向分欄時，按讚等按鈕的文字換行，溢出 12px。改為一行並自動縮小字體。

## 備註

- 在模擬器上，全螢幕底部的按鈕位於系統手勢區，adb 的點擊會被系統先接走。實機手指點擊不受影響。
