# 需求：卡片排數同步、全部影片卡片可預覽、直播預覽與小視窗

日期：2026-11-07　狀態：已確認（使用者 2026-11-07 提出並回答選擇題；第一批）

## 驗收條件

- **AC-1**：首頁「直播」「番劇」「影視」分頁的卡片排數，依「影片卡片排數」設定（直向、橫向分開）：設為固定 N 排時就是 N 排；設為「自動」時維持各分頁原本依寬度計算的排法。旋轉螢幕後立即換成對應排數。
- **AC-2**：App 內所有一般影片卡片都可以預覽，和首頁推薦相同：長按卡片在卡片上預覽；第二次長按開啟原本的選單；預覽中點卡片，影片頁從預覽位置接著播。範圍：
  - 影片頁相關影片（直向、橫向分欄、全螢幕推薦面板）
  - 熱門、排行／分區、搜尋結果、收藏夾、稍後再看、觀看紀錄、UP 主影片、合集
  - 原本長按是存圖或選單的卡片，改為第二次長按才出現。
- **AC-3**：上述有捲動清單的頁面也支援「滑動時預覽」（手指停在卡片上約 0.25 秒開始預覽），遵守既有的「滑動時預覽」開關。
- **AC-4**：直播卡片（首頁直播、關注的直播、直播分區、搜尋直播）長按可以預覽直播畫面（靜音，可切換聲音）；預覽中點卡片進入直播間。
- **AC-5**：離開直播間時（返回或斜下滑），直播以 App 內小視窗繼續播放，和一般影片相同：
  - 可拖曳、吸附角落、雙指縮放。
  - 點小視窗回到同一個直播間。
  - X 關閉。
  - 遵守「返回時縮小為小視窗」「斜下滑縮小為小視窗」設定。

## 不做的範圍

- 「縮小視窗」只在直播間與影片頁，不加在卡片上。
- 番劇與影視的卡片（海報）不加預覽：它們是劇集入口，不是單一影片。
- 豎屏模式（第二批，見 `docs/work/reels-mode/1-requirements.md`）。
