# 需求：影片卡片統一與滑動預覽卡頓

日期：2026-11-06　狀態：已確認（使用者透過問答選定樣式、範圍與大小設定方式）

## 目標

讓所有影片列表看起來一致（和首頁相同的直式卡片），使用者可以用一個設定調整卡片大小；並消除首頁滑動時因為開始預覽而造成的卡頓。

## 驗收條件

### 卡片統一

- **AC-1**：搜尋結果的「綜合」影片列表，卡片樣式與首頁相同：封面在上（16:10，與首頁相同）、標題在下最多兩行、下方顯示播放數／彈幕數與 UP 主名稱，多欄網格排列。
- **AC-2**：以下頁面的影片卡片也使用 AC-1 的直式樣式：熱門、分區排行、每週必看、入站必刷、UP 主影片（網頁版投稿列表）、收藏夾內容與收藏夾搜尋、訂閱合集內容、音樂相關影片。
- **AC-3**：影片頁下方的「相關影片」維持原本的橫式卡片。收藏夾「排序」頁（拖曳排序）維持橫式。
- **AC-4**：直式卡片保留原卡片的功能：點擊開啟影片、封面上的時長與角標、觀看進度條、長按（行動裝置）／右鍵（桌面）開啟原本的選單、右下角「⋮」選單（有提供時）、收藏夾的多選遮罩與擁有者的「取消收藏」按鈕。收藏夾中的番劇簡介在直式卡片省略。
- **AC-5**：手機直向時，同一個寬度設定下，首頁與搜尋結果的卡片寬度相同（截圖量測誤差在 2dp 內）。橫向時首頁左側有導覽列，欄數可能不同，不在此條範圍。

### 大小設定

- **AC-6**：設定中有一個「影片卡片寬度」滑桿，首頁與 AC-2 的所有頁面共用此值；調整後寬度越小，每列欄數越多。
- **AC-7**：原本「主頁」寬度的使用者設定值沿用為新的共用寬度（升級後首頁外觀不變）。其他列表（直播、番劇、歷史、稍後再看、下載、相關影片等）的寬度設定不受影響。

### 滑動預覽卡頓

- **AC-8**：在首頁連續上下滑動（手指一直移動）時，不會開始任何預覽；左右滑動切換分頁時也不會開始預覽。
- **AC-9**：手指停在一張卡片上約 0.25 秒（期間移動不超過 12dp）才開始預覽該卡片。
- **AC-10**：開始或切換預覽時，列表滑動不出現明顯頓一下：在模擬器上以 profile 模式量測，預覽開始前後 1 秒內沒有超過 32ms 的 UI 執行緒影格。
- **AC-11**：長按預覽、CC 字幕、靜音、進度條與點擊後延續預覽位置的既有功能維持正常。

## 不做的範圍

- 不改影片頁「相關影片」與收藏夾排序頁的樣式。
- 不改直播間、番劇、專欄、動態等非一般影片卡片。
- 觀看紀錄、稍後再看、離線快取列表使用各自的卡片（含多選、刪除等），本次不改。
- 不在搜尋等其他頁面加入長按／滑動預覽（只有首頁有預覽）。

## 限制

- Flutter／Dart，Android 為主要平台，桌面版不能壞。
- 介面文字只用繁體中文（台灣用語）。
- 設定鍵沿用既有的 `recommendCardWidth`，不新增會讓舊設定失效的鍵。
