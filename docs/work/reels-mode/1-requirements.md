# 需求：豎屏模式（類似 IG Reels）

日期：2026-11-07　狀態：已確認（使用者 2026-11-07 選擇 API 來源與完整版）

## 目標

像官方 App 的「豎屏」與 IG Reels：豎屏影片可以全螢幕直向觀看，往上滑直接換下一部豎屏影片。

## 已確認的決定

- 影片來源：串接 B 站 App 的豎屏推薦 API（story feed）。如果 API 無法使用，改為從首頁推薦中篩選豎屏影片。
- 畫面：完整版。
  - 基本：全螢幕直向，上下滑換片，點一下暫停，底部進度條，標題，UP 主。
  - 右側操作：按讚、投幣、收藏、分享、評論（開啟評論面板）、關注 UP、彈幕、「完整影片」（開一般影片頁）。
- 入口：
  1. 首頁上方分頁新增「豎屏」，放在「推薦」與「熱門」之間；分頁內是卡片格線，點卡片才進入全螢幕豎屏模式（2026-11-07 使用者修改，原本是分頁內直接全螢幕播放）。
  2. 豎屏影片的播放器顯示「豎屏」按鈕（和官方 App 相同位置），點選後以目前影片進入豎屏模式，往上滑接續推薦。

## 驗收條件

- AC-1（2026-11-07 依使用者要求修改）：首頁「推薦」與「熱門」之間出現「豎屏」分頁，內容為影片卡片格線（排數跟隨「影片卡片排數」設定）；點卡片以全螢幕豎屏模式播放，從該影片開始，往上滑接續推薦，往下滑回上一部。
- AC-2：豎屏影片的播放器有「豎屏」按鈕；點選後進入豎屏模式，從目前影片與目前進度開始。
- AC-3：右側操作按鈕都可以使用，狀態（已讚、已投幣、已收藏、已關注）正確顯示。
- AC-4：滑到清單最後前自動載入更多，不會中斷。
- AC-5：只顯示豎屏影片（高大於寬，考慮旋轉）；API 回傳的橫式影片略過。
- AC-6：離開豎屏分頁、進入其他頁或 App 到背景時暫停；回來時繼續。
- AC-7（2026-11-07 依使用者要求新增）：一部影片播完後自動播放下一部；沒有下一部時重播目前這部並載入更多。
