# 需求：一鍵投放影片到 PiliBTRTV

## 目標

使用者在手機 PiliBTR 看影片時，按一個按鈕，就讓同一個 Wi-Fi 裡電視上的 PiliBTRTV 從手機目前的進度接著播同一部影片。

## 使用者決定（2026-11-14）

- 投放內容：影片投放（不做遙控、不做一鍵登入）。
- 找電視：自動搜尋為主，找不到時可掃電視上的 QR code 或手動輸入 IP。
- 安全：第一次投放要在電視上按「允許」配對，未配對的手機不能讓電視播放。
- 投放後：手機暫停。

## 驗收條件

- AC-1：手機影片頁（一般影片與番劇）有「投放到電視」按鈕；按下後在 3 秒內列出同一個 Wi-Fi 裡開著 PiliBTRTV 的電視（顯示電視名稱）。
- AC-2：找不到電視時，畫面提供「掃描 QR code」與「輸入 IP」兩種方式；電視設定中有「投放配對」頁顯示 QR code 與 IP:埠。
- AC-3：第一次投放到某台電視時，電視跳出「允許 <手機名稱> 投放？」，按允許後才開始播；按拒絕或 30 秒沒回應，手機顯示「電視拒絕投放」。之後同一支手機投放不再詢問。
- AC-4：投放後電視開啟該影片（同一個分 P／集數），從手機目前的位置開始播放（誤差 3 秒內），不被電視的歷史紀錄進度覆蓋。
- AC-5：投放成功後手機的影片暫停，並顯示「已投放到 <電視名稱>」。
- AC-6：電視正在播別的影片或在其他頁面時，投放仍會切換到新影片。
- AC-7：電視上可以移除已配對的手機；移除後該手機再投放需要重新允許。
- AC-8：電視不在線、IP 錯誤或網路逾時，手機在 5 秒內顯示錯誤訊息，不卡住影片頁。

## 不做的範圍

- 手機遙控電視（播放、暫停、進度、音量）。
- 一鍵登入電視帳號。
- DLNA／Chromecast 等標準協定、投放到其他 App。
- 直播投放（之後可加）。
- 跨網段或外網投放。

## 限制

- 兩個 repo 都要改：PiliBTR（`gordonpow/PiliBTR`）與 PiliBTRTV（`C:\presonal_project\PiliBTRTV`）。
- 電視端沿用現有區網伺服器 `LocalServer`（`dart:io` HttpServer，埠 3322～3331，啟動時就開）。
- 配對憑證只存在兩端本機，不經過外部伺服器；請求不帶 B 站帳號資料。
- 介面文字用繁體中文，並補英文語言包字串。
