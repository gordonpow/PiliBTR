# 需求：快取與下載捷徑、影片頁推薦排數、自動連播倒數、選單精簡、載入相關預設值、下載進度條

日期：2026-11-07　狀態：已確認（使用者 2026-11-07 提出 7 項）

## 驗收條件

- **AC-1**：影片頁簡介中長按「快取」或「下載」按鈕，直接開啟「快取與下載」頁。長按「快取」時開在「快取」分頁，長按「下載」時開在「下載」分頁。短按的行為不變。
- **AC-2**：設定新增「影片頁推薦排數（橫向）」：自動、1、2、3、4，預設「自動」。只套用在橫向左右分欄時右側的相關影片；直向、全螢幕推薦面板、首頁不受影響。「自動」依右欄寬度與卡片寬度計算，不使用首頁的固定排數。
- **AC-3**：播放順序「自動連播」改成 YouTube 式：
  - 影片播完後，在播放器上顯示「接下來播放」卡片（下一部的封面與標題），並從 5 秒開始倒數，卡片上有「取消」與「立即播放」。
  - 倒數結束後播放下一部。
  - 倒數期間，使用者捲動相關影片清單時，停止倒數，卡片顯示已取消。
  - 播放順序的預設值改為「自動連播」（只影響從未設定過的使用者）。
- **AC-4**：播放器「⋮」選單移除「過載影片」「播放器音量」「選擇畫質」「彈幕設定」「彈幕列表」。這些功能在播放器的其他按鈕（畫質按鈕、彈幕按鈕）仍可使用。
- **AC-5**：「提前初始化播放器」預設開啟。
- **AC-6**：會加快影片載入、但目前預設關閉的設定都改為預設開啟：「提前初始化播放器」（同 AC-5）與「啟用 HTTP/2」。其他相關設定（硬解、免登入 1080P、自動播放、首頁預覽、CDN 測速、BTR 播放加速）已經是開啟，維持不變。
- **AC-7**：MP4 下載卡片（底部進度卡與「下載」分頁）與快取分頁的進度條改細：高度 3dp、圓角，不顯示 Material 3 的結尾圓點，軌道顏色淡。

## 不做的範圍

- 不改直播頁。
- AC-5、AC-6 只改預設值；使用者自己設過的值不覆寫。
