# 需求：快取與下載管理器、全域網速單位、速度微調按鈕

日期：2026-11-07　狀態：已確認（使用者 2026-11-07 提出，並回答 3 個選擇題）

## 目標

在「我的」集中管理離線快取與 MP4 下載，可以直接播放、刪除、控制進行中的下載，並看到即時網速。網速單位全 App 統一，可在設定中調整。

## 驗收條件

### 速度微調
- **AC-1**：播放器倍速選單的滑桿左右各有「−」「+」按鈕，每按一次調整 0.05 倍並立即套用（範圍 0.25～4.0）。

### 全域網速單位
- **AC-2**：設定 → 網路與加速新增「網速單位」：自動（預設；低於 1 MB/s 顯示 KB/s）、KB/s、MB/s、Mbps。
- **AC-3**：App 內所有顯示網速的地方都使用這個單位：CDN 狀態面板、CDN 測速、快取與下載的即時網速。改設定後下次顯示就生效。

### 快取與下載頁
- **AC-4**：「我的」的「離線快取」改名「快取與下載」。頁面有「快取」「下載」兩個分頁。
- **AC-5**：「快取」分頁保留現有功能。正在快取的項目顯示即時網速，並有「暫停／繼續」「停止」按鈕：
  - 「停止」：確認後刪除這個快取並移出佇列。
  - 「暫停／繼續」：保留進度。
- **AC-6**：「下載」分頁列出 App 下載的 MP4（標題、封面、大小、日期），新的在上面。檔案已被手動刪除的項目不顯示。
- **AC-7**：進行中的 MP4 下載顯示在「下載」分頁最上面：進度、階段（下載中／合併中／已暫停）、即時網速，以及「暫停／繼續」「停止」按鈕。
  - 暫停後，可以從原進度繼續。
  - 「停止」：取消並刪除暫存檔。
- **AC-8**：兩個分頁的已完成項目都可以刪除。單筆刪除用長按選單，刪除前需確認；刪除時，檔案與紀錄一起刪掉。
- **AC-9**：點已完成的項目，在畫面中央開啟播放彈窗（16:9）：
  - 控制：播放／暫停、進度條、時間、關閉、全螢幕切換。
  - 快取的 DASH 檔案影音同步播放。
  - 關閉彈窗後停止播放。
  - 快取項目的長按選單另有「在影片頁開啟」（原本的行為）。

## 不做的範圍

- 舊版下載、沒有紀錄的 MP4 不會出現在「下載」分頁（不掃描整個 Download 資料夾）。
- 不支援同時進行多個 MP4 下載（維持一次一個）。

## 限制

- 介面文字只用繁體中文（台灣用語）。
- 下載紀錄存在 `GStorage.localCache`，不隨 WebDAV 同步。
