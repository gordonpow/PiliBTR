# 需求：設定介面樹狀分類與設定搜尋紀錄

日期：2026-11-06　狀態：已確認（使用者 2026-11-06 回覆「好」）

## 目標

現有設定分成 9 個平面分類，項目混雜（例如「其它設定」同時有搜尋、代理、下載路徑），不好找。改成多層樹狀頁面，並讓設定搜尋可直接看到搜尋紀錄、在結果中直接操作設定。

## 驗收條件

### 1. 樹狀分類（多層頁面）

- **AC-1**：設定首頁只顯示第一層分類；點分類進入第二層子分類；點子分類才顯示設定項。沒有子分類的分類直接顯示設定項。結構如下：

  ```
  設定
  ├ 播放
  │  ├ 畫質與音質
  │  ├ 播放行為
  │  ├ 手勢與操作
  │  ├ 全螢幕與旋轉
  │  ├ 小視窗與子母畫面
  │  ├ 彈幕
  │  └ 字幕
  ├ 網路與加速（BTR、CDN、緩衝、代理、重試、HTTP/2）
  ├ 內容
  │  ├ 首頁推薦
  │  ├ 評論
  │  ├ 動態
  │  └ 搜尋
  ├ 外觀
  │  ├ 主題與顏色
  │  ├ 版面與導覽
  │  ├ 字型與縮放
  │  ├ 圖片
  │  └ 動畫
  ├ 帳號與隱私
  ├ 下載與儲存
  ├ 其他
  ├ 更新
  ├ WebDAV
  └ 關於
  ```

- **AC-2**：現有每個設定項都出現在新樹中恰好一個位置，沒有遺漏或重複（以腳本或清單比對新舊項目數）。
- **AC-3**：每個分類列顯示名稱與簡短說明（列出主要包含的設定）。
- **AC-4**：設定項的行為與儲存的值不變（只搬位置，不改 key 與預設值）。
- **AC-5**：平板／橫向時沿用現有的左右雙欄版面：左側顯示目前層級的分類，右側顯示選中的內容。
- **AC-6**：「更新」項目的紅點在新結構中仍顯示。

### 2. 設定搜尋紀錄

- **AC-7**：點設定頁的搜尋後、尚未輸入文字時，直接顯示搜尋紀錄（最近 20 筆，新的在上）。
- **AC-8**：點紀錄填入搜尋框並顯示結果；每筆紀錄可單獨刪除，另有「清除全部」。
- **AC-9**：送出搜尋（按鍵盤搜尋鍵）或點選某個結果時記錄該關鍵字；重複的關鍵字移到最上面，不重複出現。
- **AC-10**：搜尋結果直接顯示設定元件，開關可直接切換、選項可直接點開調整，不必跳到原分類頁；每筆結果標示所在路徑（例如「播放 › 小視窗與子母畫面」）。

## 不做的範圍

- 不改任何設定的 key、預設值與行為（第一批的預設值變更除外）。
- 不新增或刪除設定項。
- 搜尋紀錄不同步到 WebDAV。

## 限制

- 介面文字只用繁體中文（台灣用語）或英文。
- 在第一批（`player-gestures-pip-rotation`）完成後實作，以免設定檔案互相衝突。
