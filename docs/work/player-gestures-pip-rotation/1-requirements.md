# 需求：全螢幕三區手勢、子母畫面、小視窗縮放、背景播放、橫向頁面與旋轉偵測

日期：2026-11-06　狀態：已確認（使用者 2026-11-06 回覆「好」）

## 目標

讓 PiliBTR 在手機上的播放與旋轉體驗接近 YouTube App：全螢幕可用手勢叫出推薦、直接縮小成小視窗；回主畫面可用子母畫面繼續看；首頁等頁面可隨手機自動旋轉橫向顯示；先轉橫再開影片也能直接全螢幕。

## 驗收條件

### 1. 全螢幕三區塊手勢

- **AC-1**：全螢幕播放時，畫面寬度分成左、中、右三個區塊；左右寬度相同，中間寬度 = 設定值（佔螢幕寬度的百分比）。
- **AC-2**：設定 → 外觀新增「全螢幕中間區塊寬度」，用滑桿調整（範圍 20%–60%，預設 34%）。拖動滑桿時，對話框內的橫向播放器示意圖即時顯示三區塊的寬度，不必按確定才看到。
- **AC-3**：全螢幕時在左區塊上下滑調整亮度、右區塊上下滑調整音量，行為與目前相同。
- **AC-4**：全螢幕時在中間區塊上滑，從底部滑出推薦清單（一般影片為相關推薦，番劇為選集），影片繼續播放；點選項目直接切換到該影片並保持全螢幕；下滑清單或點清單外的影片區域收起。
- **AC-5**：全螢幕時在中間區塊下滑，或在畫面任何位置向左下、右下斜滑，影片跟著手指縮小移動（與目前直向斜滑縮小相同的跟手動畫）；放開超過門檻後退出全螢幕並變成 App 內小視窗，未超過門檻則彈回全螢幕。
- **AC-6**：非全螢幕（直向）時的手勢行為不變。

### 2. 子母畫面

- **AC-7**：播放設定中的「背景畫中畫」改名為「子母畫面」，預設關閉。
- **AC-8**：開啟「子母畫面」後，在影片頁（含全螢幕）或 App 內小視窗播放中按 Home 或返回主畫面，出現系統子母畫面小窗並繼續播放同一部影片；關閉時不出現。

### 3. 小視窗雙指縮放

- **AC-9**：App 內小視窗可用兩指捏合／張開調整大小，放開後維持該大小並吸附角落。
- **AC-10**：播放設定的「小視窗大小」新增「自訂」選項；雙指縮放後自動切換為「自訂」，並記住大小，下次開小視窗沿用；選回小／中／大時使用預設尺寸。
- **AC-11**：縮放有最小與最大限制（不小於螢幕短邊 30%，不大於螢幕短邊 95%，也不超出可用畫面）。

### 4. 切到背景時是否暫停

- **AC-12**：「背景繼續播放」預設改為開啟（新安裝與從未改過此設定的使用者）；使用者仍可在播放設定中關閉，關閉後切到背景會暫停、回到前景會繼續。

### 5. 橫向頁面

- **AC-13**：「橫屏適配」在手機上也預設開啟（從未改過此設定的使用者）。
- **AC-14**：橫屏適配開啟且系統「自動旋轉」開啟時，首頁、關注、我的等頁面隨手機轉向切換直向／橫向版面；系統自動旋轉關閉時，維持直向不旋轉。

### 6. 持續偵測旋轉方向

- **AC-15**：手機已經是橫向（且系統自動旋轉開啟）時點開影片，影片頁載入後直接進入橫向全螢幕。
- **AC-16**：播放中任何時候轉成橫向會進入全螢幕、轉回直向會退出（手動進入的全螢幕除外），連續開多部影片、從小視窗放大後都仍有效。

### 7. 預設全螢幕方向

- **AC-17**：「預設全螢幕方向」的預設值改為「不改變當前方向」（從未改過此設定的使用者）。直向時按全螢幕維持直向全螢幕；橫向時維持橫向。已改過的使用者沿用原設定。

### 8. 「屏」改為「螢幕」

- **AC-18**：介面文字（設定標題、說明、選單、提示）中與螢幕相關的「屏」依下表替換，替換後 `grep` 介面字串不再出現「屏」（伺服器比對用的字串常數除外，保留原文並加註解）：

  | 原文 | 改為 |
  |---|---|
  | 全屏 | 全螢幕 |
  | 橫屏 | 橫向螢幕 |
  | 豎屏 | 直向螢幕 |
  | 小屏 | 小螢幕 |
  | 摺疊屏 | 摺疊螢幕 |
  | 轉屏 | 旋轉螢幕 |
  | 黑屏 | 黑畫面 |
  | 息屏 | 關閉螢幕 |
  | 投屏 | 投放 |
  | 刷屏 | 洗版 |
  | 屏蔽 | 封鎖 |
  | 屏幕（簡體殘留） | 螢幕 |

  語句不通順時可調整字詞（例如「橫屏適配」改為「橫向螢幕適配」）。

## 不做的範圍

- 非全螢幕狀態的三區塊手勢與推薦清單。
- 直播頁的推薦清單與全螢幕斜滑縮小（直播目前不支援小視窗）。
- 子母畫面中的彈幕顯示行為（沿用現有「子母畫面不顯示彈幕」設定）。
- iOS、桌面平台的新行為（只針對 Android 手機）。

## 限制

- Android 手機為主；不能破壞平板、桌面現有行為。
- 介面文字、註解、commit 只用繁體中文（台灣用語）或英文。
- 改預設值只影響從未設定過的使用者（Hive 已有值者不覆寫）。
- 不新增相依套件（現有 `native_device_orientation` 可用）。
